# OrcaXCare — Client

React (Vite 8). Hướng dẫn đầy đủ: [README.md](../README.md) ở thư mục gốc.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build → dist/
```

API dev: proxy `/api` → `http://localhost:5000` (xem `vite.config.js`). Tùy chọn `VITE_API_URL` trong `.env.example`.
